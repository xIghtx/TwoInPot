# 시설 스토리와 추가 검토 항목

플레이 중에는 전체 진상을 설명하지 않는다. 두 캐릭터가 중립적인 디지털 훈련실을 통과하고, 뒤로 갈수록 오래된 보관 흔적·반복된 번호·삭제된 기록을 발견한다. 기록은 짧고, 누가 무엇을 했는지와 두 캐릭터의 정체는 단정하지 않는다. 직접적인 잔혹 묘사는 없다.

## 구현 범위

- 1–3: 적응실. 비교적 깨끗한 회색 격자와 청록 표시등.
- 4–6: 보관 구역. 보랏빛 조명과 응답 없는 보관함.
- 7–9: 재조정실. 낡은 황갈색 조명과 더 많은 보관 흔적.
- 10–12: 반환 통로. 어두운 청회색 공간과 불분명한 퇴실 신호.
- 3·6·9·12 스테이지 본 도전에서 각자 색의 기록 표식에 1.2초 함께 머무르면 선택 기록 복원.
- 기록은 해당 플레이의 재시도에서 유지하고, 처음부터 다시 시작하면 초기화.
- 네 기록을 복원한 뒤 최종 협동 게이트를 통과하면 다른 엔딩. 기록 없이도 게임을 끝낼 수 있음.
- 기록과 엔딩은 호스트가 결정하며 참가자에게 동기화.

## 추가 검토 목록

다음 항목은 의미를 확정하지 않고 보류했다. 현재 진행과 엔딩 구현을 막지 않는다.

1. ‘컴퓨터 그래픽 같은 느낌’이 2D 픽셀 격자실을 뜻하는지, 초기 3D 렌더 풍경까지 원하는지. 현재는 사용자가 확정한 2D 도트 형식을 유지했다.
2. 대상 어린이의 구체적 연령과 기록 문장 독해 수준. 현재 어휘와 어두운 암시를 행사 주최 측이 검토할 필요가 있다.
3. 시설 운영자의 정체, 캐릭터가 사람인지 복제된 기억인지, 기록 삭제의 정확한 원인. 의도적인 빈칸으로 두었다.
4. 트루 엔딩을 공략 없이 어느 정도 찾을 수 있게 할지. 현재 두 색 표식과 짧은 안내는 보이지만 엔딩 조건 전체를 미리 설명하지 않는다.
5. 장기 저장·클리어 기록 유지 여부. 현재 수집은 한 번의 플레이 세션 범위이며 저장 슬롯·계정 기록은 미구현.
6. 독자적인 음향·음악·음성 연출. 이번 그래픽 및 스토리 작업에는 미포함이며, 저작권이 확인된 최종 오디오 자산은 별도 제작 대상.
7. 실제 두 번째 노트북에서의 프레임과 LAN 플레이, 어린이의 전체 플레이 시간 및 난이도. 로컬 두 프로세스 테스트와 별도로 현장 확인이 필요하다.
