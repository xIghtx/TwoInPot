# TWO IN POT — 밝은 협동 등반 버전

## 이번 수정 방향

항아리에 얼굴과 발이 붙은 캐릭터를 없애고, 피지컬은 사람이 항아리에 들어가 망치로 몸을 밀거나 끌어올리는 등반가로 바꿨다. 뇌지컬은 고글, 작업 조끼, 공구 가방과 다리를 가진 기술자로 제작했다. 두 역할은 색상 외에 외형과 실루엣이 다르다. 역할을 바꾸면 각 플레이어에게 해당 모델만 표시된다.

어린이 체험을 고려해 둥근 얼굴, 안전모와 큰 고글, 밝은 하늘과 구름, 부드러운 언덕, 나무·돌 장치를 사용한다. 거친 사실 묘사나 어두운 폐허 분위기로 만들지 않았다. 모델은 Unity에서 생성한 메시이며 원본 게임의 모델을 가져오지 않는다.

## 조작

| 역할 | 키 | 동작 |
|---|---|---|
| 피지컬 등반가 | A/D 또는 좌우 방향키 | 망치를 회전한다. 걷기 입력이 아니다. |
| 피지컬 등반가 | Space | 망치가 닿은 바닥·발판을 밀어 몸을 띄운다. |
| 피지컬 등반가 | Space를 누른 채 A/D | 벽에 망치를 붙잡고 회전시켜 몸을 끌어올린다. |
| 뇌지컬 기술자 | A/D 또는 방향키 | 일반 구간에서는 이동, 장치 조작 구간에서는 장치를 제어한다. |
| 뇌지컬 기술자 | Space | 점프 또는 시간제 문 조작. |
| 2번 발사 스테이지 | 피지컬 Space / 뇌지컬 A/D | 기존의 충전 발사 / 각도 협동 조작을 사용한다. |

망치 접촉은 반경 0.16의 판정으로 보정하고, 접촉 직전 0.12초의 Space 입력을 기억한다. 바닥에서 Space를 누르고 있으면 다시 밀어오를 수 있다. 벽 붙잡기는 Space를 떼면 풀린다. 빈 공중에서 버튼을 눌러도 자유 점프가 생기지 않는다.

카메라·충돌체를 흔들거나 늘리지 않고 표현용 모델에만 작은 착지 반응과 기울기를 적용한다. 팔은 어깨와 망치 손잡이를 따라 움직이며 망치의 방향·접촉·붙잡기 상태는 서버에서 동기화한다. 모든 스테이지에서 추락 시 해당 스테이지 출발점으로 복귀한다.

## 스테이지

12개 스테이지와 역할별 기믹 연습을 유지한다. 피지컬 연습 목표는 실제 망치 접촉으로 몸을 띄우는 것으로 바꿨다. 3·5·7·8·11·12에는 낮은 바위와 나무 계단을 추가하고 출구 높이를 맞춰 등반하는 흐름을 보강했다. 뇌지컬은 이동 발판, 바람, 상자, 문, 다리, 승강기와 릴레이를 제어한다.

목표 플레이 시간과 실제 난이도는 어린이 키보드 체험으로 추가 확인해야 한다. 전체 스테이지 자동 검사는 진행 조건의 검사이며 어린이가 직접 완주했다는 뜻이 아니다.

## 파일과 실행

- Unity 6000.6.0f1, Assets/TwoInPot/Scenes/Prototype.unity.
- Builds/Windows/TwoInPot.exe. 두 노트북에는 Windows 폴더 전체를 같은 버전으로 복사한다.
- 네트워크 식별자는 `TwoInPot:climber:3`으로 바꿨다. 앞선 항아리 캐릭터 빌드와 섞어서 접속할 수 없다.
- 수정 전 코드·씬·프리팹은 Docs/Backups/BeforeClimberUpgrade에 보관한다.
- 제작 갱신 메뉴: Two In Pot > Upgrade Festival Edition.
- 검증·이미지·빌드 결과: Docs/Verification/ClimberResults.md.

## 사용자 검토와 미구현

요청 범위에서 필수 사용자 승인 때문에 보류한 기능은 없다. 현재 모델과 난이도는 검토 가능한 구현 초안이다.

- 미구현: 행사 대기줄에 맞춘 짧은/전체 코스 선택 메뉴와 제한 시간 설정.
- 추후 검토: 두 역할의 외형 디테일, 실제 어린이의 망치 키보드 조작 난이도와 완주 시간.
- 음악·효과음 및 별도 아티스트의 모델·리깅은 이번 수정에서 추가하지 않았다.
