# Two In Pot — 창의융합축제 로드맵

## 목표 경험

- **대상:** 초등 저학년을 우선 기준으로 하며, 나이와 게임 경험이 달라도 설명을 듣고 바로 함께 시작할 수 있게 한다.
- **운영 환경:** 축제 부스의 노트북 2대와 두 명의 참가자. 각자 자기 노트북의 내장 키보드로 플레이한다.
- **한 팀 플레이 시간:** 보통 5~8분, 길어도 10분 안에 끝난다. 실패해도 즉시 재도전할 수 있고 게임 오버나 긴 대기 화면은 없다.
- **핵심 재미:** 한 명은 움직이고 다른 한 명은 장치를 조작한다. 서로 말하고 도와야 길이 열리는 협동을 경험한다.
- **네트워크:** 두 노트북을 같은 전용 Wi-Fi/LAN에 연결하고 직접 IP로 접속한다. 인터넷 서비스나 계정은 축제 기본 진행에 필요하지 않게 한다.

## 현재 상태 — 저장소 확인 기준

### 들어 있는 것

- Unity 프로젝트와 `Prototype.unity` 씬
- Netcode 기반 2인 세션 코드: 직접 IP 연결, Unity 온라인 방 코드, 접속 종료 처리
- 피지컬/로직 역할 선택·상호 수락 UI
- 1~8단계 월드 및 런타임 기믹 코드
- 발사 각도 조정·힘 충전·발사, 이동 발판, 바람, 자석 상자, 속도문, 회전 다리, 마지막 스위치
- 한국어·영어 UI 문구

### 축제 버전에 필요한 일

- 운영자가 두 노트북을 미리 연결하는 축제용 호스트/참가 흐름과 네트워크 사전 점검
- IP 입력과 방화벽 처리는 운영자가 맡고, 참가자는 각자 키보드 조작에 집중하는 흐름
- 짧은 튜토리얼, 단계별 진행, 도움말, 완주 화면
- 어린 참가자에게 읽기 쉬운 큰 글자·그림 안내·명확한 색과 모양 신호
- 5~10분 플레이 흐름과 막힘 방지 장치
- 부스에서 인터넷 없이 시작·재시작 가능한 Windows 빌드
- 실제 플레이 검증

> README의 일부 구현 현황은 현재 코드와 다릅니다. 이 로드맵은 README보다 씬·런타임 코드·에셋을 기준으로 작성했습니다. 코드와 씬 파일이 있다는 사실만으로 플레이 검증까지 끝났다고 보지는 않습니다.

## 축제용 플레이 흐름

| 구간 | 예상 시간 | 참가자가 하는 일 |
|---|---:|---|
| 시작·역할 고르기 | 20~40초 | 두 플레이어 색과 역할을 고르고 조작을 익힌다. |
| 1단계: 문 열기 | 40~60초 | 로직이 스위치를 누르고 피지컬이 문을 통과한다. 기본 협동을 배운다. |
| 2단계: 함께 발사 | 60~90초 | 로직이 방향을 맞추고 피지컬이 힘을 충전해 발사한다. |
| 3단계: 움직이는 발판 | 45~75초 | 한 명이 발판을 움직이는 동안 다른 한 명이 건넌다. |
| 4단계: 자석 상자 | 45~75초 | 상자를 옮겨 파트너의 발판을 만든다. |
| 마지막: 최종 스위치 | 45~75초 | 스위치를 유지하고 파트너가 출구에 도달한다. |
| 축하·다음 팀 넘기기 | 20~40초 | 완주를 축하하고 한 번의 조작으로 새 팀을 시작한다. |

예상 플레이는 안내와 보통의 재시도를 포함해 약 **5~8분**이다. 두 노트북 연결은 운영자가 참가 전에 준비해 플레이 시간에 포함하지 않는다. 선택한 5개 구간은 현재 1·2·3·5·8단계 기믹을 활용한다. 현재의 4·6·7단계는 삭제하지 않고 축제 시간 연장용 보너스 경로로 보존한다. 실제 시간 측정 후 구간 수와 난이도를 조정한다.

## 구현 로드맵

### 0단계 — 축제용 범위와 현 상태 고정

1. Unity에서 프로젝트를 열어 컴파일 오류와 현재 씬 참조를 확인한다.
2. 현장 네트워크를 확정한다. 우선 전용 공유기 또는 두 노트북이 서로 통신 가능한 같은 Wi-Fi를 쓰고, 행사장 Wi-Fi가 기기 간 통신을 막으면 대체 네트워크를 준비한다.
3. 두 노트북을 같은 네트워크에 연결해 직접 IP 접속을 확인하고, UDP 7777 및 방화벽 허용 여부를 사전 점검한다.
4. `FestivalRoute`를 두어 본편 순서를 1→2→3→5→8로 구성하고, 보너스 단계는 선택형으로 둔다.
5. 시작부터 완주까지 현재 기준 플레이 시간을 기록한다.

**완료 기준:** 두 노트북이 행사장 네트워크에서 직접 연결되고, 각 키보드 입력으로 각자의 플레이어가 움직이며, 본편 단계 순서와 진행 조건이 문서화된다.

### 1단계 — 두 노트북 LAN 협동 MVP

1. 두 노트북을 같은 네트워크에 연결하고, 호스트 노트북은 `HOST ON THIS PC`, 참가 노트북은 호스트의 로컬 IP로 `JOIN BY IP`를 사용한다.
2. 각 노트북의 키보드가 연결된 플레이어만 조작하는지 확인한다. 기본 조작은 A/D 또는 방향키, Space이며 단계별 특수 조작은 화면에서 다시 안내한다.
3. 축제 기본 화면은 LAN 호스트/참가 흐름을 가장 먼저 보이게 하고, 인터넷 방 코드는 보조 메뉴로 둔다.
4. 운영자가 플레이 시작 전에 연결을 준비할 수 있도록 연결 상태, 호스트 IP, 오류·재시도 안내를 단순화한다.
5. 역할 선택, 스위치, 발사, 발판, 출구 판정이 두 기기에서 동기화되는지 확인한다.

**완료 기준:** 인터넷 서비스 계정 없이 같은 LAN에서 두 노트북이 연결되고, 각 참가자가 자기 키보드로 플레이하며, 5개 본편 구간을 끝까지 함께 완료할 수 있다.

### 2단계 — 어린이용 안내와 막힘 방지

1. 시작 화면에 3개 이하의 짧은 그림 안내를 보여준다: 이동, 점프/발사, 파트너를 돕기.
2. 각 단계 시작 때 목표를 한 문장과 그림으로 보여주고, 플레이 중에는 필요한 조작만 크게 표시한다.
3. 색만으로 역할·위험·성공을 구분하지 않는다. 색에 아이콘·테두리·문구를 함께 쓴다.
4. 약 20초 동안 진전이 없으면 짧은 힌트를 띄우고, 더 오래 막히면 안전한 재배치·쉬운 경로를 제안한다.
5. 추락·실패 뒤 2초 안에 가까운 지점에서 다시 시작하고, 성공 상태를 잃지 않게 한다.

**완료 기준:** 처음 보는 참가자 둘이 성인 설명 없이 첫 협동 퍼즐을 시작하고, 막혀도 도움말만으로 다시 진행할 수 있다.

### 3단계 — 축제 부스 UX와 완주 흐름

1. 성공·실패·대기 화면을 친근하고 짧게 만든다. 긴 설명이나 작은 글자를 피한다.
2. 마지막에 두 플레이어가 함께 축하받는 완주 화면을 보여주고, `다시 하기`와 `다음 팀`을 분명히 구분한다.
3. 한 번의 버튼 입력으로 초기화하고, 운영자가 마우스/키보드로 방·계정 설정을 만질 필요를 없앤다.
4. 플레이하지 않는 동안에는 조작법을 보여주는 attract 화면을 띄운다.
5. BGM·효과음은 음소거 가능하게 하고, 모니터 스피커가 꺼져도 목표와 성공을 알아볼 수 있게 한다.

**완료 기준:** 팀 교대가 20초 안에 끝나고, 다음 참가자가 이전 팀의 상태를 이어받지 않는다.

### 4단계 — 두 기기 빌드와 현장 검증

1. 두 노트북을 행사장과 같은 네트워크에 연결해 인터넷 없이 실행·완주·초기화를 확인한다.
2. 2인 플레이 5회 이상을 재서 중앙값 5~8분, 최대 10분 안쪽인지 기록한다.
3. 어린 참가자 관찰 플레이에서 설명 없이 시작 가능한지, 어느 구간에서 막히는지 기록한다.
4. 키보드 창 포커스 이탈, Wi-Fi 끊김, 참가자 재접속, 호스트 종료, 재시작을 점검한다.
5. 두 노트북에 실행 파일과 필요한 데이터를 준비하고, 참가자 계정·관리자 권한 없이 실행되는지 확인한다.

**완료 기준:** 부스 네트워크에서 두 노트북이 안정적으로 연결되고, 운영자가 새 팀을 쉽게 시작시키며, 인터넷 서비스에 의존하지 않고 다섯 구간을 완주할 수 있다.

### 5단계 — 선택 확장

- 보너스 4·6·7단계로 8~10분 경로 제공
- 온라인 방 코드 모드의 별도 시연
- 추가 스테이지·역할 조합·효과음·장식 추가
- 역할을 바꿔 같은 코스를 다시 플레이하는 재도전 모드

## 우선순위

1. **최우선:** 현재 씬 실행·컴파일 확인, 한 PC 로컬 협동, 인터넷 없는 시작과 재시작
2. **다음:** 5개 본편 경로, 안내·힌트·빠른 재시작
3. **그다음:** 어린이 사용성·플레이 시간 측정, 부스 PC 빌드 안정화
4. **나중:** 보너스 단계, 온라인 기능 확장, 장식 콘텐츠

## 축제용 완료 판정

- 운영자가 미리 네트워크와 호스트/참가 연결을 준비한다. 참가자 2명은 30초 안에 역할과 키보드 조작을 이해하고 시작한다.
- 기본 경로는 보통 5~8분, 가장 느린 일반 플레이도 10분 안에 끝난다.
- 한 명이 실패해도 파트너가 기다리는 시간이 길지 않고 바로 재도전할 수 있다.
- 도움말과 진행 표시를 화면 가까이에서 읽을 수 있다.
- 두 노트북이 같은 로컬 네트워크에서 인터넷 서비스 없이 실행·완주·초기화된다.
- 운영자 한 명이 짧은 안내와 팀 교대만으로 여러 팀을 받을 수 있다.

## 현재 검증 공백

- 이 로드맵 작성 시점에는 Unity Play 모드 컴파일, 두 명 동시 조작, 오프라인 플레이 시간, 어린이 사용성, 축제용 Windows 빌드를 검증하지 않았다.
- 원본 ZIP의 사전 빌드는 현재 프로젝트 폴더에 없다. 실행 파일을 배포하려면 새로 빌드해야 한다.
