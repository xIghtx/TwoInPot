# 체험판 확장 — 2026-10-30

## 이번 변경

- 방을 닫고 다시 열거나 상대가 나가면 이전 체험을 초기화한다. 스테이지, 연습, 역할 수락, 선택 기록, 엔딩, 개인 메모, 추가 통로 진행을 새로 시작한다. 언어/효과음 설정은 유지한다.
- 기존 12개 방의 고유 기믹을 통과한 뒤 추가 통로 3곳을 진행한다. 기존 시작점 x -6~-11에서 첫 출구 x11까지였던 길을 최종 x36까지 늘렸다. 실제 플레이 시간은 사람이 측정해야 한다.
- 방별 조합은 신호 통로/발사 시험실/운반 회로/바람 덕트/자석 보관고/가속 검문소/균형 교량/기억 문/승강 회랑/시간 잠금실/추 균형실/최종 반환로.
- 추가 지형은 계단, 벽을 잡는 기둥, 엇갈린 선반, 낮은 천장을 방/장치 순서별로 조합한다. 바닥 안전지대와 중간 복귀 지점을 둔다.
- 주황색은 접촉한 망치 머리가 노란색으로 바뀌고 예상 이동 점선을 본다. SPACE 누르기/떼기와 기존 벽 잡기는 유지한다. 점선은 최초 발사 방향의 참고이며 전체 충돌 시뮬레이션을 보장하지 않는다.
- 파란색은 기존 A/D·SPACE 장치 조작에 더해 Q/E로 회로 입력 숫자를 고르고 ENTER로 확정한다. 주황색 화면의 표식을 물어봐야 한다.
- 숫자 회로: 들은 숫자에 1 또는 2를 더하되 4 다음은 1. 다음 장치는 더하는 양이 달라진다.
- 기억 회로: 들은 숫자 순서를 뒤집어 입력한다. 틀리면 처음부터 다시 입력한다.
- 연결 회로: 버튼은 자기 불과 양옆 불을 함께 바꾼다. 주황색이 읽어 준 불빛 모양으로 만든다. 시간 제한이나 생명 차감은 없다.
- 초반 두 숫자, 중반 세 숫자, 후반 네 숫자로 점진적으로 늘린다. 연결 회로는 4개 불빛이며 모든 목표의 해가 존재함을 계산 검사했다.
- 올바른 회로 입력만으로 구간이 끝나지 않는다. 주황색이 중간 표식을 순서대로 찍고 마지막 깃발에 도달해야 다음 스테이지다.
- 기존 네 선택 기록과 트루 엔딩 조건·내용은 유지한다. 개인 메모 결과에 따른 일반 후일담도 유지한다. 추가 통로 문제는 개인 비밀 미션과 별개다.

## 제출/실행

두 PC 모두 최신 배포 ZIP 전체로 교체해야 한다. 프로토콜 festival-circuits:8. 예전 ZIP은 이번 변경을 포함하지 않는다.
