# Two In Pot: 픽셀 아트 기준

## 확인한 자료와 적용 범위

- 사용자가 제공한 Sonic 계열 스프라이트 시트: `ArtReferences/User16BitAnimationReference.png`. 작은 실루엣, 동작별 형태 변화, 선명한 색 구획의 품질 참고 자료다. 이미지에 적힌 저작자 표시는 사용자 지시가 아니며, 게임 에셋으로 복사하지 않았다. 해당 시트를 공식 Sonic Mania 제작 자료라고 단정하지 않는다.
- [Sonic Mania 공식 화면](https://sonic.sega.jp/SonicMania/): 보관한 `ArtReferences/SonicMania/stage_ss_01.jpg`, `04.jpg`, `07.jpg`의 게임 플레이 화면을 관찰했다. 오프닝 애니메이션은 분석 대상이 아니다.
- 정지 JPEG에서 원본 해상도, 실제 팔레트 색 수, 프레임 수, 제작 도구, 패럴랙스 속도를 확정할 수 없다. 아래 수치는 Two In Pot 구현 선택이며 Sonic Mania의 제작 수치라는 주장이 아니다.

## 1. 픽셀 표현

**관찰 가능한 특징:** 작은 계단식 윤곽과 큰 면 덩어리가 같은 픽셀 격자 안에서 연결된다. 명암은 분리된 색 띠이고, 세부 질감과 하이라이트는 필요한 부위에 집중된다. 모든 면에 디더링을 넣지는 않는다.

**화면의 역할:** 작은 캐릭터도 몸·얼굴·발이 구분되고, 재질은 적은 정보로 읽힌다. 매끈한 벡터 곡선이나 흐릿한 보간 확대와 달리 경계의 위치가 명확하다.

**새 장면 적용:** 캐릭터·장치는 같은 월드 픽셀 밀도, Point 필터, 밉맵·텍스처 압축 없는 임포트. 640×360 내부 화면을 정수배 확대한다. 몸의 주색은 약 세 단계로 묶고, 노이즈를 세부 묘사로 대체하지 않는다.

## 2. 캐릭터 스프라이트

**관찰 가능한 특징:** 큰 머리·몸통·신발 색 구획, 밖으로 뻗는 팔다리, 기울어진 달리기와 원형 회전 등 포즈 자체가 동작을 설명한다. 첨부 시트에는 걷기·달리기·점프·압축된 자세가 서로 다른 실루엣으로 들어 있다.

**화면의 역할:** 표정의 잔디테일을 읽지 않아도 이동 방향과 행동을 알 수 있다. 중간 프레임은 단순 위치 보간 이상의 과장을 만든다. 정확한 재생 간격은 정지 자료만으로 확인할 수 없다.

**새 장면 적용:** 주황 단색 계열의 지점토 사람이 항아리에 들어가고, 하늘색 지점토 사람은 두 다리·고글·가방으로 구별된다. 항아리·망치·고글·가방은 별도 재질색을 쓴다. 대기·눈깜빡임·준비·버티기·상승·낙하·착지와 기술자의 네 달리기 포즈를 연결한다. 착지 압축·발사 신장·짧은 접촉 불꽃은 물리 콜라이더를 변형하지 않는다.

## 3. 환경 디자인

**관찰 가능한 특징:** 반복 지형의 위쪽 경계와 옆면이 구분된다. 식물·체커 흙·금속 패널 등은 구역에 따라 달라지며, 전경 지형과 먼 배경은 세부 밀도·명도로 나뉜다. 화면에 나타난 경사·곡선은 주행 경로를 연결한다.

**화면의 역할:** 반복 타일이 큰 공간을 만들고, 장식과 충돌 가능한 표면을 구분한다. 체커 흙·야자수는 특정 구역의 소품이지 스타일 전체의 필수 요소가 아니다.

**새 장면 적용:** 사용자 수정에 따라 자연 지형을 최종 방향에서 제외한다. 격투게임 훈련실 같은 회색 격자 벽, 금속 발판, 셔터, 콘솔, 레일을 사용한다. 바닥의 가는 밝은 테두리와 장치 표시등으로 행동 경로를 만든다. 메커니즘과 충돌체 위치는 유지한다.

## 4. 색과 명암

**관찰 가능한 특징:** 캐릭터와 상호작용 물체의 선명한 색이 상대적으로 어둡거나 조용한 배경 위에서 읽힌다. Green Hill의 풀·흙·물 색과 Studiopolis의 네온·기계 패널은 서로 다른 구역 팔레트다.

**화면의 역할:** 모든 요소에 높은 채도를 똑같이 주지 않고 주목 순서를 만든다. 밝은 면과 그림자 면은 중간의 무수한 그라데이션 없이 재질을 설명한다.

**새 장면 적용:** 배경은 저채도 남색·회색, 캐릭터는 주황·하늘색, 조작 콘솔은 녹색, 진행 표식은 밝은 청록색이다. 진행 구역별로 청회색 → 보랏빛 회색 → 낡은 황갈색 조명 → 어두운 청회색으로 바뀐다. 캐릭터 뒤에 같은 채도의 큰 주황·하늘색 면을 놓지 않는다.

## 5. 화면 구성과 움직임

**관찰 가능한 특징:** 횡방향으로 넓은 공간, 캐릭터 앞의 이동 여유, 작지만 또렷한 고리·스프링·플랫폼이 보인다. 서로 다른 깊이의 배경 구성은 확인되지만, 패럴랙스 속도와 구현은 정지 화면만으로 검증되지 않는다.

**화면의 역할:** 다음 행동 지점을 먼저 볼 수 있고 작은 상호작용 물체가 배경 장식에 묻히지 않는다.

**새 장면 적용:** 현재 협동 스테이지 전체를 보여주는 고정 카메라를 유지한다. 월드 세로 시야 15유닛, 내부 세로 360픽셀로 24픽셀/유닛을 맞춘다. 현재 고정 화면에는 인위적인 카메라 패럴랙스를 추가하지 않았다. 장치의 실제 이동·문 개폐·망치 접촉은 즉시 화면에 반영한다.

## 6. 효과와 UI

**관찰 가능한 특징:** 충돌·먼지·반짝임은 작은 픽셀 덩어리이며, HUD는 구석의 명확한 문자·숫자와 강한 명암으로 읽힌다.

**화면의 역할:** 효과는 입력이 성공했음을 알려주고 HUD는 플레이 공간을 과도하게 덮지 않는다.

**새 장면 적용:** 실제 착지에만 짧은 먼지, 실제 망치 접촉에만 불꽃을 쓴다. 파티클 오브젝트를 미리 만들고 재사용한다. UI는 각진 남색 패널·주황/하늘색 강조로 통일하고, 어린이가 읽어야 하는 한글은 화면 해상도로 선명하게 유지한다. 스토리는 짧은 기록과 배경 흔적으로 드러내며 긴 해설 화면으로 플레이를 멈추지 않는다.

초등학생 기준으로 복원된 문장은 16초 표시하며 장치 근처에서 다시 읽을 수 있다. 발견 장치의 수집 번호·전체 개수·엔딩 조건은 표시하지 않는다. 어두운 설정은 파란 승인 손도장·사진의 관리자 표기·짧은 지시문으로 드러낸다. 접촉·착지·장치 반응에는 원본 PCM 효과음을 쓰고, 음소거를 지원한다.

## 핵심 규칙 8개

1. 명확한 픽셀 격자와 Point 확대를 유지한다.
2. 큰 형태와 실루엣을 세부 질감보다 먼저 읽히게 한다.
3. 재질당 적은 명암 단계와 선택적인 하이라이트를 쓴다.
4. 동작마다 실루엣을 바꾸고, 콜라이더는 안정적으로 유지한다.
5. 주황·하늘색 몸과 외부 물체의 재질색을 분리한다.
6. 전경·장치·배경에 다른 명도와 채도 우선순위를 준다.
7. 반복 타일의 경계, 장치 표시, 목표 형태를 즉시 알아보게 한다.
8. 특정 Sonic 구역의 소품을 복제하는 대신 원래 게임의 디지털 훈련 시설을 만든다.

## 오리지널 스테이지 아트 디렉션

‘반환 통로’: 저채도 청회색 격자실, 닳은 금속 발판의 얇은 청록 테두리, 두 개의 셔터와 서로 떨어진 콘솔. 진행 영역은 밝고, 뒤쪽에는 응답하지 않는 보관함이 남는다. 주황 등반가와 하늘색 기술자가 각각의 표식에 머무르면 기록 장치가 연녹색으로 바뀐다. 과거를 설명하는 전지적 해설·시체·잔혹 묘사는 넣지 않는다. 마지막 통로의 의미는 수집한 기록과 엔딩의 짧은 문장으로 추측하게 한다.

## 이탈 점검표

- [ ] 실제 게임 크기에서도 캐릭터 역할과 포즈가 읽힌다.
- [ ] 부드러운 벡터 곡선·블러·광택 렌더처럼 보이지 않는다.
- [ ] 윤곽의 픽셀 크기와 월드 픽셀 밀도가 서로 맞는다.
- [ ] 몸에 피부색·옷색·머리카락을 추가하지 않았다.
- [ ] 항아리·망치 등 외부 물체까지 몸색으로 칠하지 않았다.
- [ ] 배경과 캐릭터가 명도·채도로 분리된다.
- [ ] 풀이 많은 들판 등 폐기한 분위기가 최종 맵에 남지 않는다.
- [ ] 게이트·콘솔·목표·안전한 발판이 장식과 구분된다.
- [ ] 반복 지형의 이음새나 투명 구멍이 눈에 띄지 않는다.
- [ ] 접촉·착지 효과가 실제 행동과 맞는다.
- [ ] 스토리 문장이 전체 진상을 직접 해설하지 않는다.
- [ ] 30fps 목표는 실제 실행 측정으로 판단하며 평균만으로 최저 프레임을 보장하지 않는다.

## 생성 및 에셋 출처

래스터 에셋은 내장 image_gen 도구로 제작했다. 최종 원본은 `Assets/TwoInPot/Art/Pixel/Source/`에 저장했다. `ClayCharacters.png`, `WorkshopTiles.png`, `WorkshopBackground.png`, `StoryDecals.png`를 사용한다. Unity 임포트 과정에서 최근접 표본화·알파 정리·정식 Sprite Editor Data Provider를 통한 프레임 슬라이싱을 수행하며 원본은 보존한다. 아틀라스별 재질에 텍스처를 명시해 배경 텍스처가 다른 스프라이트에 적용되는 문제를 방지한다.

사용한 최종 프롬프트의 핵심: 캐릭터는 첨부 시트의 픽셀 제작 품질만 참고하고 기존 주황/하늘색 캐릭터 정체성을 유지한 4×4 프레임 시트. 배경은 저채도 남색 회색 격투게임 훈련실, 320×180 논리 격자, 낮은 원근 바닥, 자연물·글자·캐릭터 제외. 지형은 같은 밀도의 4×4 금속 패널·콘솔·셔터·표식·레일·망치·먼지·불꽃·UI·스프링 시트. 자연 풍경 버전은 최종 적용 대상에서 제외했다.

스토리 흔적 프롬프트: 128×128 논리 격자의 2×2 투명 픽셀 데칼 시트. 서로 다른 높이의 주황·하늘색 손자국, 글자 없이 덧씌워진 이름표, 작은 손자국이 남은 빈 이중 보관 장치, 일부 지워진 청록 화살표와 희미한 표시등. 저채도 회색 재질, 적은 명암 단계, 피·시체·괴물·잔혹 묘사 제외. 이 흔적은 진행 구역에 따라 차례로 노출한다.
