# 효과음

게임 내장용 짧은 모노 PCM 효과음 9종을 직접 합성했다. 외부 샘플이나 기존 게임의 소리를 복사하지 않았다. 삼각파·사인파·짧은 노이즈로 디지털 훈련실과 어울리는 소리를 만들었다.

| 파일 | 발생 시점 | 길이 |
| --- | --- | ---: |
| Select.wav | 메뉴 선택·장치 표식의 반응·연습 완료 | 0.07초 |
| Contact.wav | 망치가 지형에 닿는 순간 | 0.065초 |
| Push.wav | 망치로 몸을 밀어 올릴 때 | 0.16초 |
| Land.wav | 실제 낙하 후 착지 | 0.11초 |
| Jump.wav | 하늘색 캐릭터 점프 | 0.15초 |
| Gate.wav | 문이 열릴 때 | 0.25초 |
| Record.wav | 선택 장치가 복원될 때 | 0.22초 |
| Clear.wav | 다음 구간으로 진행 | 0.32초 |
| Ending.wav | 두 엔딩 공통 | 0.48초 |

원본은 `Assets/TwoInPot/Audio/`에 있다. `FestivalAudioBuilder`가 22,050Hz·16비트 WAV를 생성하고 Unity에서 압축 없이 불러온다. 원본 파형 최대 진폭은 0.42 이하이며, 재생 음량은 0.24로 시작한다. 네 AudioSource를 재사용하고, 반복 접촉음은 간격을 제한한다. 공간 음향은 사용하지 않는다.

설정의 ‘효과음 끄기/켜기’는 해당 PC의 소리만 제어한다. 기록 복원음은 짧고 중립적인 반응음이며, 두 엔딩에도 같은 소리를 사용한다. 소리만으로 트루 엔딩 경로를 정답처럼 알려주지 않는다. 배경 음악·음성·장기 게임 저장은 이번 범위에서 제외했다.

자동 검사는 클립 연결·길이·모노 채널·실제 파형 신호·클리핑 여유·조용한 끝부분·음소거·재생 재개를 확인한다. 행사장 스피커에서의 체감 음량과 소리 선호도는 현장 확인 대상이다.
