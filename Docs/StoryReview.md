# 시설 스토리와 추가 검토 항목

플레이 중에는 전체 진상을 설명하지 않는다. 두 캐릭터가 중립적인 디지털 훈련실을 통과하고, 뒤로 갈수록 오래된 보관 흔적·덧씌운 이름표·삭제된 기록을 발견한다. 짧은 문장과 환경 단서를 통해 인물의 과거와 의도를 추측하게 한다. 직접적인 잔혹 묘사는 없다.

## 사용자가 확정한 설정

1. 공간은 **2D 픽셀 격자실**이다. 초기 3D 그래픽으로 전환하지 않는다.
2. 대상은 **초등학생 기준**으로 설계한다. 안내와 기록은 짧게 쓰며, 복원된 문장은 16초 표시하고 해당 장치 근처에서 다시 읽을 수 있다.
3. 두 캐릭터는 **사람**이며, **파란 캐릭터가 시설 운영자**다. 기록 삭제는 고장이나 사고가 아니라 **파란 인물의 의도**였다. 이 설정은 사진의 관리자 표기·파란 승인 손도장·고장이 아니라는 쪽지로 나누어 드러낸다. 삭제한 이유의 구체적인 동기는 이번 답변에서 정해지지 않았으므로 새로 단정하지 않는다.
4. 선택 행동은 공략 없이 발견할 수 있으나, ‘이것이 트루 엔딩 경로’라고 확신하게 만들지 않는다. 수집 번호·전체 개수·엔딩 조건 안내는 게임 화면에 표시하지 않는다. 가까운 불빛·입장 시 짧은 소리·복원된 문장만 반응한다.
5. **장기 저장은 제외**한다. 기록은 한 번의 플레이 세션에만 유지한다. 언어 선택 같은 기존 설정 저장과는 별개다.
6. **짧은 효과음 구현**: 선택, 망치 접촉·밀기, 착지, 점프, 게이트, 선택 장치, 구간 완료, 엔딩. 설정에서 효과음을 끌 수 있다. 음악·음성은 추가하지 않았다.
7. **현장 검증은 아직 못 한 상태**로 둔다. 다른 노트북·실제 어린이·현장 네트워크 검증을 완료했다고 표시하지 않는다.

2026-10-28에는 한 PC에서 두 프로세스를 실행해 루프백과 자체 Wi-Fi IPv4 접속, 12스테이지·기록·두 엔딩·효과음을 검증했다. [검사 결과](Verification/NetworkResults.md). 다른 노트북과 현장 검증은 여전히 미확인이다.

## 구현 범위

- 1–3: 적응실. 비교적 깨끗한 회색 격자와 청록 표시등.
- 4–6: 보관 구역. 보랏빛 조명과 응답 없는 보관함.
- 7–9: 재조정실. 낡은 황갈색 조명과 더 많은 보관 흔적.
- 10–12: 반환 통로. 어두운 청회색 공간과 불분명한 퇴실 신호.
- 3·6·9·12 스테이지 본 도전에서 각자 색의 기록 표식에 1.2초 함께 머무르면 선택 기록 복원.
- 기록은 해당 플레이의 재시도에서 유지하고, 처음부터 다시 시작하면 초기화.
- 네 기록을 복원한 뒤 최종 협동 게이트를 통과하면 다른 엔딩. 기록 없이도 게임을 끝낼 수 있음.
- 기록과 엔딩은 호스트가 결정하며 참가자에게 동기화.

2026-10-28 보강: 12개 방의 환경 문장을 각각 다르게 추가했다. 각 역할에만 전달되는 수신 메모와 자신의 완료율에 따른 일반 엔딩 후일담을 추가했다. 두 노트북에서 다른 일반 후일담을 볼 수 있으며, 상대의 메모·완료율·순위는 표시하지 않는다. 기존 네 기록 복원 조건과 트루 엔딩 원문은 유지한다. [메모와 후일담 규칙](PrivateNotes.md).

## 아직 확인하지 않은 항목

- 실제 초등학생의 독해 속도·조작 난이도·전체 플레이 시간.
- 선택 장치의 발견률. ‘발견하기 어렵다’와 ‘정답 경로가 너무 뻔하다’ 사이의 균형은 현장 관찰로 조정한다.
- 두 번째 노트북의 프레임과 실제 LAN 연결, 행사장 스피커의 효과음 음량.
- 파란 인물이 기록을 지우기로 한 구체적인 동기. 현재는 사용자 설정 범위까지만 반영했고, 배신·구원·실험 목적 등 추가 결론은 임의로 정하지 않았다.

이 항목들은 현 구현을 막는 승인 요청이 아니다. 장기 저장은 미완료 과제가 아니라 사용자 결정에 따라 제외한 범위다.
