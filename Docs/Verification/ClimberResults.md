# 밝은 협동 등반 버전 — 최종 검증

## 제작 상태

피지컬은 사람이 쇠항아리에 들어간 안전모 등반가, 뇌지컬은 큰 고글과 조끼·가방·다리를 가진 기술자로 제작했다. 두 역할은 별도의 외형 그룹을 사용하며 역할 선택에 따라 해당 그룹만 표시한다. 밝은 하늘·구름·둥근 언덕·나무와 돌 장치로 어린이에게 맞춘 분위기를 적용했다.

피지컬의 일반 걷기와 자유 점프를 망치 회전, 지형 접촉 밀기, 벽 붙잡기와 끌어오르기로 바꿨다. 뇌지컬의 장치 조작과 이동, 2번 협동 충전 발사는 유지한다. 12개 스테이지의 연습 안내를 새 조작에 맞췄고 6개 스테이지에 완만한 등반 계단과 높은 출구를 추가했다.

## 검사한 동작

- 실제 두 프로세스 접속, 역할 선택·수락 RPC, 참가자 소유 입력 RPC 전달.
- 피지컬의 등반가 외형과 뇌지컬의 기술자 외형이 각각 활성화되는지 확인.
- A/D가 피지컬을 걷게 하지 않고 망치만 회전시키는지 확인.
- 실제 바닥 접촉으로 몸 밀기, 모델 반응, 착지.
- 빈 공중의 Space 입력으로 자유 점프가 생기지 않는지 확인.
- 접촉 직전 Space 입력을 기억하고 접촉 시 밀기.
- Space로 벽 붙잡기, 망치 회전으로 몸 끌어올리기, Space를 떼면 해제.
- 뇌지컬이 협동 문을 열면 그 문에 걸린 망치도 풀리는지 확인.
- 1~12 전부: 연습 시작, 연습 중 출구 조기 통과 차단, 초기화와 출발 위치, 실제 역할별 연습, 입력 기록 초기화, 본 도전 전환, 클리어 및 다음 스테이지/최종 완료.
- 공중 발사 버튼 해제만으로 연습이 완료되지 않는지 확인.
- 승강기 최저점에서 실제 장치 변화가 없는 입력만으로 연습이 끝나지 않는지 확인.
- 바람 이동, 승강기 탑승 상승, 시간제 문 열림·닫힘·재열림.
- 마지막 릴레이의 첫 문 유지·두 번째 콘솔·조기 완료 차단, 마지막 완료 유지와 게임 전체 초기화.
- 참가자 UI의 연습 카드와 네트워크 단계가 일치하는지 확인.

## 남은 검토와 진단

자동 검사는 같은 컴퓨터의 두 실행 파일을 로컬 UDP로 연결해 수행했고, 일부 경우는 서버에서 위치와 입력을 지정했다. 실제 두 노트북의 학교 네트워크, 인터넷 방 코드/Relay, 어린이 직접 조작의 난이도·완주 시간은 아직 검증하지 않았다. 모든 스테이지를 사람이 키보드로 직접 완주했다는 의미는 아니다.

실행 시작 부분에 이전 버전에서도 관찰한 Unity `Curl error 23: Failure writing output to destination, passed 293 returned 0` 진단이 한 번 남았다. 호출 원인은 로그에서 특정하지 못했으며 해결된 것으로 간주하지 않는다. 이후 게임 연결·그래픽 실행·위 검증은 모두 통과하고 정상 종료했다.

사용자 승인이 필수라서 보류한 요청 기능은 없다. 행사 짧은/전체 코스 선택 메뉴와 제한 시간 설정은 미구현이며, 외형 디테일과 어린이 조작 난이도는 현재 초안을 보고 검토할 항목이다.
