# 픽셀·훈련 시설·스토리 버전 검증

이 문서는 2026-10-27 초기 픽셀 빌드 기록이다. 이후 확정한 스토리 설정·효과음·네트워크와 현재 성능은 [2026-10-28 검증](NetworkResults.md)을 참고한다.

최종 검증: 2026-10-27. Unity 6000.6.0f1, Windows x64 Development, Direct3D 11.

## 결과

- Windows 빌드 성공. 실행 파일: `Builds/Windows/TwoInPot.exe`.
- 실제 호스트와 참가자 두 프로세스의 통합 검사: **호스트 972개, 참가자 577개 확인 통과**, 양쪽 종료 코드 0.
- 12개 스테이지 모두 연습 진입·출구 건너뛰기 방지·리셋·기믹 연습·본 도전·클리어 통과.
- 망치 회전·접촉 밀기·공중 점프 방지·입력 버퍼·벽 붙잡기·끌어올리기·게이트 개방 시 접촉 해제 확인.
- 바람·승강기·시간제 문·최종 릴레이·처음부터 다시 시작 확인.
- 두 역할의 픽셀 프레임·Point 필터·기존 플레이어 MeshRenderer 비활성화·스프라이트 지형·640×360 내부 화면 확인.
- 망치 상승 시 상승 포즈, 역할별 외형 분리 확인.
- 기록은 한 사람만으로 복원되지 않음. 두 사람이 표식에 함께 머무르면 복원되고, 재시도에서는 유지됨.
- 연습 단계에서 기록 복원 불가. 네 번째 기록 없이 일반 엔딩, 네 기록을 복원하면 트루 엔딩으로 분기.
- 참가자에게 기록·트루 엔딩 동기화. 처음부터 다시 시작하면 기록과 엔딩 초기화.

확인 개수에는 반복 UI·렌더러 확인이 포함된다. 서로 다른 테스트 시나리오가 1,549개라는 의미는 아니다. 전체 스테이지를 사람이 직접 완주한 결과가 아니라, 서버 입력·위치 제어를 포함한 실제 네트워크 실행 검사다.

## 성능

같은 PC에서 두 실행 파일을 동시에 구동. 창 출력 설정 1280×720, 내부 게임 화면 640×360. 숨겨진 창에서 자동 렌더링이 생략되는 영향을 피하기 위해, 명시적인 개발 검사 옵션에서 매 프레임 카메라 렌더링을 강제로 수행했다. 아래 값은 12개 스테이지와 엔딩 검사 중 실제 월드 렌더링 부하를 포함한다. UI 전체의 눈에 보이는 창 검증은 별도로 수행했다.

| 측정 | 호스트 | 참가자 |
| --- | ---: | ---: |
| 평균 | 59.9fps | 59.9fps |
| 느린 1% 평균 | 50.3fps | 50.8fps |
| 95백분위 프레임 시간 | 16.7ms | 16.7ms |
| 가장 느린 프레임 | 30.1ms | 27.9ms |
| 33.33ms 초과 | 0 / 2715 | 0 / 2746 |

측정 구간에서는 30fps 목표를 충족했다. 시작 직후 5초 및 로비는 통계에서 제외한다. 이 결과는 현재 PC의 측정이며 두 번째 행사 노트북과 현장 네트워크 성능은 별도 확인 대상이다.

## 화면 확인

- 실제 창에서 언어 선택·한국어 메뉴·로컬 호스트·역할 선택 표시와 클릭을 확인했다.
- 즉시 모드 GUI가 UI Toolkit을 가리던 문제는, 낮은 정렬 순서의 Canvas/RawImage 출력으로 교체해 해결했다.
- 일부 지형에 배경 텍스처가 적용되던 문제는 정식 아틀라스 임포트 및 아틀라스별 명시적 텍스처 재질로 해결했다.
- 실제 런타임 카메라 화면: `../Previews/TrainingRoomStage01_Final.png`, `../Previews/ReturnChannelStage12_Final.png`.
- 캐릭터 비교 미리보기: `../Previews/ClayCharacters_Final.png`.
- 런타임 카메라 캡처에는 UI Toolkit HUD가 포함되지 않는다. UI는 실제 게임 창에서 별도로 확인했다.

## 근거와 남은 확인

- `PixelUpgrade.log`: 최종 빌드 성공 기록.
- `PixelHost.log`, `PixelGuest.log`: 통합 검사 및 성능 원문.
- 종료 시 Unity의 ComputeBuffer 해제 경고가 한 번 남는다. 프로젝트 런타임 코드에서는 해당 버퍼를 생성하지 않으며, 게임 중 예외나 검사 실패는 없었다. 엔진/패키지 종료 경고의 정확한 소유자는 이번 작업에서 확정하지 않았다.
- 실제 어린이의 조작 난이도·플레이 시간, 두 번째 노트북/LAN, 선택 기록 발견 난이도, 어두운 암시의 연령 적합성, 오디오·세션 간 저장은 `../StoryReview.md`에 별도로 정리했다.
