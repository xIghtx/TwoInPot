# SPACE 충전 이동과 네트워크 수정 — 2026-10-30

- W/S 힘 조절은 사용자 수정 지시에 따라 제거했다.
- 항아리는 SPACE를 눌러 힘을 모으고 뗄 때 한 번 민다. 짧게 누르면 최대의 65%, 0.75초 이상 누르면 100%. 미는 가로/세로 속도에 동일하게 적용한다.
- 누른 채 바닥에서 자동으로 반복 점프하지 않는다. 벽을 누른 채 붙잡고 A/D로 끌어올리는 동작은 유지한다. 벽 잡기를 놓을 때 원치 않는 충전 점프가 발생하지 않게 한다.
- 접촉이 있어야 밀 수 있으며 공중에서는 추가 점프가 없다. 착지 직전 뗀 입력은 0.16초 유지해 접촉 순간 밀 수 있다. 재시도/리스폰/입력 시간초과는 충전을 초기화한다.
- 연속 입력 60Hz reliable → 20Hz unreliable, 점프/떼기는 별도 reliable RPC. 네트워크 tick 60 → 30. Transport MaxPacketQueueSize 128 → 1024. 오류를 숨기지 않는다.
- HUD와 연습 안내를 SPACE 충전/떼기 방식으로 변경. 미션의 내부 수치 표현을 짧은 행동 안내로 교체했다.
- 프로토콜 hold-release:7. 양쪽 PC 모두 최신 Builds/Windows 폴더 전체로 교체해야 한다.
- HoldReleaseBuild.log 빌드 통과. 숨김 두 프로세스 검사 호스트 1044회, 참가자 1394회 통과, 종료 코드 모두 0. 충전 중 자동 발사 방지, 긴 입력의 더 강한 밀기, 충전 표시 초기화, 공중 추가 점프 방지·착지 직전 버퍼, 벽 잡기·해제, 12개 방과 개인 미션·엔딩을 검사했다.
- HoldReleaseHost.log / HoldReleaseGuest.log에 send queue full 오류 없음. 입력 트래픽 감소와 대기열 설정은 적용했지만, 실제 LG 노트북에서 제보된 오류의 재현 환경은 아직 미검증이다.
- 평균 59.5/59.7fps, 1% 하위 36.9/44.6fps. 최악 프레임 117.3/106.1ms로 순간 지연은 남아 있다. 다른 노트북 성능 보장은 아니다.
