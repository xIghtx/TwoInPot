## 두 노트북에서 시작

한쪽에서 로컬 방을 만들고 다른 쪽에서 호스트의 IPv4 주소로 참가합니다. 같은 PC에서 두 개를 실행할 때만 `127.0.0.1`을 사용합니다. 역할을 서로 다르게 선택하고 둘 다 수락하면 시작합니다. 인터넷 방 코드 모드는 연결된 Unity 서비스와 인터넷이 필요합니다.

- **피지컬 / 항아리 등반가:** 주황 단색 계열의 지점토 사람과 별도로 채색한 항아리·망치. A/D 또는 방향키로 망치를 회전하고, Space를 눌렀다 떼면 지형을 밀어 몸을 띄웁니다. 약 0.75초까지 길게 누를수록 더 멀리 갑니다. Space를 누른 채 벽에 닿은 망치를 회전하면 몸을 끌어올립니다.
- **뇌지컬 / 고글 기술자:** 하늘색 단색 계열의 지점토 사람, 고글·가방과 두 다리. A/D 또는 방향키로 이동하거나 장치를 조작하고 Space로 점프·시간제 문을 조작합니다.
- **2번 발사 구간:** 피지컬은 Space를 충전 후 떼어 발사하고, 뇌지컬은 A/D로 각도를 맞춥니다.

12개 스테이지 모두 **역할별 기믹 연습 → 본 도전 → 다음 스테이지**로 진행합니다. 추락하면 해당 스테이지 출발점으로 복귀합니다. 격자형 디지털 훈련 시설의 금속 발판·셔터·콘솔을 사용하며, 구역마다 조명과 남겨진 흔적이 바뀝니다. 선택 기록과 일반 후일담 분기·트루 엔딩이 있고 전체 진상은 직접 해설하지 않습니다. 기록은 재시도에서 유지하고 처음부터 다시 시작하면 초기화합니다.

초등학생 기준으로 짧은 문장을 사용합니다. 선택 기록은 수집 번호나 엔딩 공략 없이 주변 불빛·소리로 알아볼 수 있고, 복원한 장치 근처에서 다시 읽을 수 있습니다. 조작·접촉·장치·구간 전환의 효과음이 있으며 **설정 > 효과음 끄기**로 해당 PC의 소리를 끌 수 있습니다. 장기 게임 저장은 사용하지 않습니다.

Windows 실행 파일은 GitHub Releases의 `TwoInPot_2026-10-30_CircuitEdition.zip`에 있습니다. ZIP 전체를 풀고 `TwoInPot.exe`를 실행하세요. 다른 노트북에도 같은 ZIP을 사용하세요. 앞선 항아리 캐릭터 버전과 네트워크 형식이 다르므로 두 노트북 모두 같은 새 빌드를 사용하세요.

[아트 기준](Docs/PixelArtDirection.md), [스토리와 추가 검토 목록](Docs/StoryReview.md), [픽셀 버전 검증](Docs/Verification/PixelResults.md)을 확인하세요. 내부 게임 화면은 640×360이며 Point 필터와 정수배 확대를 사용합니다. 한글 메뉴와 HUD는 화면 해상도로 표시합니다.

최신 연결·효과음·엔딩·성능 검사: [2026-10-28 단일 PC 두 프로세스 검증](Docs/Verification/NetworkResults.md). 루프백과 자체 Wi-Fi IPv4 접속을 확인했으며, 실제 두 노트북 간 LAN 검사는 아직 하지 않았습니다.

현재 아트를 다시 적용하고 빌드하는 메뉴는 **Two In Pot > Apply Pixel Art and Build**입니다. 이전 **Upgrade Festival Edition**은 3D 버전용이므로 픽셀 버전 갱신에 사용하지 않습니다. 픽셀 전환 전 씬·프리팹·표현 코드는 `Docs/Backups/BeforePixelUpgrade`에 보관합니다.
